# Troubleshooting ladder

When an answer is bad, check in order:
1. Context: did Claude have what it needed?
2. Request: was it clear?
3. Chat length: restart with a handoff?
4. Model and effort: does it need more thinking?
5. Facts: does it need a search or source?

Change ONE thing, then retry.

## Practice cases
A. Forgot to attach the report, Claude summarized anyway.
B. 70 messages in, Claude ignores the budget.
C. "Make it better" gave a rewrite I hate.
