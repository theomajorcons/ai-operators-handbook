# Document sharing checklist

Before I share:
* What do I need Claude to see? Only that.
* Never paste credentials: passwords, API keys, tokens, ID numbers. Those stay out entirely.
* Remove account numbers, addresses, other people's details.
* Do my workplace rules allow this document here?

Redact safely (not just what's visible):
* Work on a COPY, never the original.
* Remove hidden text, tracked changes, comments, and document properties (metadata).
* Export or flatten if needed (print to a fresh PDF, or export an image).
* Reopen the copy, SEARCH for what I removed, and try to COPY the redacted area.
* Confirmed gone? Only then attach.

Before I trust the answer:
* Did I ask about a specific part?
* Did Claude quote the source?
* Did I look at that page myself?
