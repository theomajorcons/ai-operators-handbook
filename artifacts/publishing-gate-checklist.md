# Publishing gate checklist

Rule: any box below answered **No** means **stop, do not publish** until it is resolved.

For each material claim, don't just link a source: vet it. **Authority** = is the
source trustworthy and ideally first-hand (Y/N)? **2nd source** = the independent
source that corroborates a load-bearing claim (link, or N/A if not load-bearing).
**Quote exact** = if you quote, the words match the original in context (Y / N/A if
no quote).
