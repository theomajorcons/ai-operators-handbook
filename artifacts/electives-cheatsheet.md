# Electives cheat sheet: Public work, measurement, and rollout

The naming rule from each elective, in one page. One rule per elective, plus the gist. Use it as a quick memory jog before you start a task.

## Elective 1: Public workflows: research and publishing
**Source Every Material Claim, Gate the Publish.** Collect sources first, draft from them marking which claim uses which source, and open the sources for every material fact. Vet each source as authoritative and first-hand, corroborate load-bearing facts with a second source, clear it to publish with no private or copied text, get a human review, disclose AI help where expected, and write for readers first.

## Elective 2: Measuring AI's impact
**Baseline, Compare, Count the Cleanup.** Time the task before AI over several runs, then time it with AI including review and fixes. Record quality as error or rework count, and cost as ongoing plus one-time setup. Payback is setup divided by net saving per week, where net subtracts weekly upkeep. No payback if upkeep wipes out the saving.

## Elective 3: Rolling AI out to a team
**Pilot, Feedback, Expand.** Pick one use case with a clear benefit, run a small pilot with volunteers, set rules for what data is allowed by your policy, and set written success, stop, and expand thresholds before you start. Collect feedback weekly, measure as in Elective 2, and decide to expand, adjust, or stop against your thresholds by a date set in advance.
