Level 2 · Lessons 7 to 14

Working with Claude

Everyday working habits in the chat app: feeding Claude documents, standing up Projects and memory, shaping outputs, researching with current sources, wiring in connectors, and fixing bad answers.

Start Level 2→

After this level you can…

  • ✓Share a document or image safely and ask questions that are answered from it, not from a vague skim.
  • ✓Set up a Project (with files and instructions) so Claude starts every chat already knowing your background and rules.
  • ✓Tell memory apart from standing instructions, and decide which a fact belongs in, or whether Claude should hold it at all.
  • ✓Ask for the right shape of output (reply, table, document, or page) and reshape one result for a new audience.
  • ✓Research a question with current sources you can judge, and connect an app with only the access it needs.
  • ✓Diagnose why an answer went wrong and fix the cause instead of retrying the same prompt.

Level 2 lessons

  1. 7Give Claude things to readExerciseSharing a document only helps if you ask narrow questions answered from the page, check where the answer came from, and strip anything private before you attach it.6 min→
  2. 8Projects, files, and instructionsExerciseA Project lets you write your background and rules once so Claude starts every chat already knowing them, instead of re-explaining yourself each time.5 min→
  3. 9Markdown and the .md file familyConceptMarkdown is plain text with three light marks for headings, lists, and emphasis, which is why it moves between tools without falling apart.5 min→
  4. 10Memory and standing instructionsExerciseStanding instructions are rules you set for every chat and memory is context Claude learns on its own, and credentials belong in neither.7 min→
  5. 11Outputs: documents, tables, and pagesExerciseAsking for the right shape of output matters as much as the content, so name whether you need a chat reply, a table, a document, or a page.6 min→
  6. 12Research and web searchExerciseWeb search lets Claude pull current sources, but a citation is only worth as much as the source behind it, so you open and judge it yourself.7 min→
  7. 13Connectors in regular chatExerciseConnecting Claude to an app is worth it only for a named job done with the least access, so default to read-only and review anything it sends or changes.5 min→
  8. 14When things go wrongConceptA bad answer has a cause, so you diagnose why it went wrong and fix that cause instead of retrying the same prompt and hoping.9 min→
