# Tool intake checklist

* Job this tool does:
* Source and why I trust it:
* Can it read? What?
* Can it modify files or records? Which?
* Can it disclose or send data outside? Where?
* Can it run code or commands?
* Can it change permissions or sharing settings?
* Can it reach the network? Which sites?
* Can it send, delete, spend, or publish?
* Smallest access it needs:
* Outside content it will touch (web, email, files):
* Could that content contain instructions? What technically stops them from acting (not just a prompt)?
* Human approval required before: modify / disclose / execute / permission change / network / send / delete / spend / publish
* Review date:
