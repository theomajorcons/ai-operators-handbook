# Output shape guide

| I need to... | Ask for |
| --- | --- |
| Understand something | A short reply |
| Compare or calculate | A table or spreadsheet |
| Keep, edit, share | A document |
| Let others use it | A page or small tool |

Always: check the contents, not just the look.

## Reshape practice
Take one result and ask for it as: (1) a table, (2) a one page handout, (3) a three sentence message.
