Glossary

Every key term the handbook defines, pulled straight from the end-of-lesson glossaries and gathered in one place. Filter by level or jump to a letter, then click through to the lesson where a term is taught.

#

.md file
A file ending in .md is a markdown file: plain text, ideally one topic per file (for example style-guide.md).Markdown and the .md file family

A

Acting agent
Claude working in a browser or desktop app that takes real actions (clicks, types, moves files, sends messages) rather than only describing them, so its output is an action that has already happened, not text you read first.Claude in the browser and desktop app
Action log
A record of what the agent did (what it clicked, moved, sent, or paused on), read afterward to verify the actions were the ones you wanted and to catch a bad one before it compounds.Claude in the browser and desktop app
Adversarial case
An input designed to push the workflow off course: a hidden instruction or a contradictory request. The eval sheet calls for three of these.Verification and evals
After time
The time the task takes with AI: the run plus review and fixes, not the AI run alone.Measuring AI's impact
Archiving
Moving older versions into a subfolder so there is exactly one current file, which stops Claude from picking the wrong version.Filesystem as context
Ask narrow
Point your question at the specific part you need, a named table, page, or section, instead of asking for a broad summary of the whole document. A narrow question gets a checkable answer.Give Claude things to read
Ask what it assumed
A one-message diagnostic ('what did you take for granted?') that gives you a hypothesis for the cause, a lead to confirm against the evidence, not proof on its own.When things go wrong
Authority
Whether you have the standing to do the action on someone's behalf. AI performs the action but does not grant you permission you did not already have.Should AI do this?
Automatic fail
A result that fails the whole capstone regardless of other scores: unauthorized data use, any uncontrolled external action, or failing any adversarial or prohibited eval case.Capstone: build and defend a system

B

Backlink
The set of notes that point to a given note. Backlinks let you, and a tool that reads your files, follow the trail in both directions, not just the way you wrote the link.Second brain: notes Claude can use
Baseline
The time a task takes before AI, measured over several runs so you have an honest starting number to compare against.Measuring AI's impact
Blast radius
How much damage a step causes if it goes wrong, and whether it can be undone. A large or irreversible blast radius is a reason to gate, but only one of the five risk questions.Planning, delegation, and human gates

C

Capstone
The final project: build a small AI workflow, prove with saved evidence that it works and that someone else can run it, and show it fails safely.Capstone: build and defend a system
Change one thing
After finding a likely cause, alter a single variable before retrying so you can tell what actually fixed the answer.When things go wrong
Chat reply (prose)
Plain paragraphs in the conversation, the default shape, best when you only need to read the answer once.Outputs: documents, tables, and pages
Check
The part of the spec that names how you will know the result is good: something verifiable like a word count or a required fact, not just 'it looks good.' The most-skipped part and the one that saves the most rework.Write a prompt like a spec
Check the computation
Verifying what Claude computed, not just that it answered: recompute one row by hand and reconcile a total against a number you already trust, because a well-formed formula can still sum the wrong thing.Claude with spreadsheets and data
Check the contents
Confirm the output is correct before you send or save it: a well-formatted file can still hold wrong numbers or claims.Outputs: documents, tables, and pages
Check the page
Ask Claude to quote or cite where an answer came from, then open the source and confirm the quote matches. Catches both broad-answer misses and scan-reading errors.Give Claude things to read
Checkable claim
A concrete, verifiable statement in an answer: a date, a number, a name, a quote, or a specific fact. It is either true or not, as opposed to tone, phrasing, or opinion, which cannot be checked the same way.Check the answer
Cite
Asking for sources with links so you can confirm where a claim came from.Research and web search
Cleanup cost
The review and rework time after an AI run; omitting it is the most common way ROI claims get inflated.Measuring AI's impact
Clear It Before You Start
The rule: scan the eight checks before handing a task to AI. All clear means go; any single no or not-sure means stop, fix the gap, or hand it to a human.Should AI do this?
Column context
Telling Claude what each column means (especially abbreviated or ambiguous headers), since it cannot open your sheet and will otherwise guess, and a confident wrong guess on data looks exactly like a right one.Claude with spreadsheets and data
Commit
A saved snapshot in Git you can return to; make one before any big change so a bad edit can be undone.Bridge: the terminal, paths, and Git
Connector
A link that gives Claude access to one of your apps (email, calendar, files) so it can read from or act on it. Availability and options vary by connector, account, plan, and administrator settings.Connectors in regular chat
Context
Everything Claude carries into a turn (the full conversation history and any attached material) alongside your new message. It is cumulative: it grows with every turn, and each turn pays for all of it.Why you hit your limitGive Claude the right context
Credentials (never share)
Passwords, API keys, access tokens, and ID numbers. They belong in neither memory nor instructions, and shouldn't be pasted into a chat at all. Keep them in a password manager.Memory and standing instructions

D

Data rules
Agreed limits on what information may be used with the tool, decided from your organization's approved data classification and AI policy (not a gut rule like 'no client names') and set before the pilot starts, because a pilot uses real work from day one.Rolling AI out to a team
Data rules on a sheet
The limits on what information may go into the tool, applied to spreadsheets where sensitive data hides in columns; strip, mask, or aggregate anything forbidden before you paste or upload.Claude with spreadsheets and data
Data sensitivity
Whether the information you feed in is cleared for the tool. Secrets, personal data, and confidential material have rules a capable model does not override.Should AI do this?
Decision date
A date set in advance to choose expand, adjust, or stop, based on measured results against your thresholds, not momentum.Rolling AI out to a team
description
The one line Claude uses to decide when a skill applies. It's the field that matters most: if a skill isn't being used, the description is almost always the problem.Reusable skills
Deterministic kill switch
A stop checked at the start of every step, pulled by creating the STOP file first and then running, so the halt is observed on purpose rather than raced against a fast run.Guided build lab, part 2: log, stop, restore
Deterministic safety-control harness
A practice workflow whose logic is fixed (here, Python keyword rules, not a model) so it behaves the same every run, letting you rehearse the controls by hand. In a real AI workflow a model replaces the fixed logic and sits behind the same controls.Guided build lab, part 1: plan, restrict, gateGuided build lab, part 2: log, stop, restore
Diagnose Before You Retry
The rule for bad answers: find the cause (context, request, chat length, model, or facts) before sending the prompt again.When things go wrong
Diff
The set of proposed changes to your files. Reading the diff before approving is how your review catches problems.Claude Code: your first safe session
Disclosure
Telling your audience where AI helped, in the places they expect to be told.Public workflows: research and publishing
Document
A keepable, editable, shareable output for something you will revisit or hand to others.Outputs: documents, tables, and pages

E

Effort
A separate dial from tier: how long Claude thinks before it answers. Higher effort buys more reasoning on the same model, independent of which tier you chose.Pick the right model
Eval
A small, deliberate test set run against an AI workflow (ten varied cases with written expected results) to find where it breaks before real work does.Verification and evals
Evidence-first diagnosis
Confirming a suspected cause by checking what actually happened (prompt, inputs and sources, tool activity and permissions, parsing and math) before changing anything.When things go wrong
Expected result
What a good answer looks like, written down before you run the case, so scoring is a clean pass or fail instead of an after-the-fact rationalization.Verification and evals

F

Failure signal
A concrete sign the current pick is too weak (a shallow answer, a missed contradiction, or a number that doesn't add up) and your cue to climb a step and verify.Pick the right model
Feedback loop
Collecting user experience weekly during the pilot so problems surface early and the prompt or process can be fixed.Rolling AI out to a team
Files
Reference material attached to a Project: a style guide, samples, a product sheet. Claude retrieves relevant slices when a chat needs them. What Claude works from, not how it works.Projects, files, and instructions
Filesystem as context
The idea that, for a tool which reads your files, the folder structure itself is the context Claude works from, so clear names and layout matter as much as the prompt.Filesystem as context
Financial payback
Setup cost divided by net dollars saved per week, where the weekly saving already has the ongoing tool, maintenance, and review costs subtracted. If ongoing costs exceed the saving, there is no payback.Measuring AI's impact
Find, Pick, Verify
The checking routine: find the checkable claims, pick the load-bearing ones, and verify them independently by going to the source, recomputing, or cross-checking, then decide to use, fix, or drop the answer.Check the answer
Flag gaps
Asking Claude what it could not find, so unknowns are visible instead of hidden behind a confident tone.Research and web search
Fresh Chat, Focused Handoff
The restart rule: notice the signs, ask Claude to write the handoff, check it, then open a new chat with only the files that still matter.Why you hit your limit

G

Gate
A checkpoint where a person must approve before Claude continues. Required whenever an action sends, spends, deletes, publishes, changes permissions, runs unreviewed code, touches sensitive data, or affects people.Planning, delegation, and human gates
Gate in the code's shape
A human-approval step built into the workflow's structure (the sort step only drafts; a separate send step moves only drafts a person approved), so there is no path for untrusted input to trigger a send and no prompt wording can bypass it.Guided build lab, part 1: plan, restrict, gate
Gated sensitive data
Health, financial, or other people's details, and confidential work material. Shareable with Claude only when all three hold: you're authorized, in an approved environment, and sharing the minimum necessary.Memory and standing instructions
git restore
A Git command that throws away unstaged edits to a tracked file, returning it to the last committed version.Bridge: the terminal, paths, and GitClaude Code: your first safe session
Guided build lab
A graded-nothing dress rehearsal on a deterministic safety-control harness: build and run one small workflow on safe synthetic data and practice each capstone control once before the capstone scores them. Split across part 1 (plan, restrict, gate) and part 2 (log, stop, restore).Guided build lab, part 1: plan, restrict, gate

H

Handoff
A short summary (what you decided, what is still open, the key facts and numbers you will need, and which files matter) that you carry into a fresh chat so you keep your progress without carrying the whole history.Why you hit your limitWhen things go wrong
Human gate
A required pause before a risky, irreversible action (send, pay, delete, publish): the agent shows the exact step and does nothing until a person says yes. Also the defense against a page that tries to hijack the agent into acting.Claude in the browser and desktop app

I

Independent check
Verifying a claim outside the answer itself, by opening the source, recomputing the number, or confirming it in a second place. Asking Claude whether it is sure is not an independent check.Check the answer
Independent pieces
Parts of a job that do not depend on each other. Splitting only pays off when the pieces are independent and large.Subagents and orchestration
Independent review
Scoring by a reviewer who is not you, plus a teammate who can run the workflow from your instructions alone. Your own sign-off does not count.Capstone: build and defend a system
Independent source
A second source with no stake in the claim; two independent sources agreeing turns a single claim into evidence.Research and web search
Index note
A top-level note that lists the main hubs of the vault, so a reader or Claude has a place to start instead of needing the right title up front.Second brain: notes Claude can use
Injected failure
A run where the input hides an instruction. You pass by showing the workflow does not obey it.Capstone: build and defend a system
Instructions
The standing rules for a Project: who you're working for, the tone, the format, what to avoid. Written once, applied to every chat in the Project. Rules, not reference.Projects, files, and instructions

J

Judge the source
Weighing who wrote it, when, and what they gain: the basis for trusting one source over another.Research and web search

K

Kill switch
A tested way to halt the automation and revoke its access immediately. An untested stop is a guess, so test it.Automation and safety

L

Least access
Granting the agent only the scope the task needs (one folder, one site, a copy of the files), so a wrong or hijacked action has a small blast radius instead of reaching everything you are signed in to.Claude in the browser and desktop app
Least privilege
Giving each tool the minimum access it needs and preferring read-only, so an injected or mistaken instruction has the smallest possible blast radius.Tools, scripts, MCP, and untrusted inputAutomation and safety
Load-bearing claim
The checkable claim the decision or next action actually rests on. You verify these first rather than every line, because a wrong one changes what you do while a cosmetic one does not.Check the answer
Long-chat problem
A single conversation grown so large it becomes expensive per turn and forgetful. Unlike the usage limit, this one is fully in your control, and fixing it is the main lever for spending less.Why you hit your limit

M

Manual mode
The permission mode (`claude --permission-mode manual`) that asks before editing files or running most commands: the recommended starting mode for beginners.Claude Code: your first safe session
Markdown
Plain text with a few visible marks that stand for structure: '#' for headings, '*' for lists, '**bold**' for emphasis, '| a | b |' rows for tables. The structure is in the characters, so any tool can read it and it survives copying.Markdown and the .md file family
MCP
A common standard for connecting Claude to outside tools and data, like a set of adapters. Install only from sources you trust, since each connection widens what Claude can reach.Tools, scripts, MCP, and untrusted input
Memory
Context Claude saves on its own as topics while you chat and can reuse later. You review it rather than write it. View, edit, delete, or pause it in Settings; Projects have separate memory; sensitive topics aren't saved by default.Memory and standing instructions
Merge step
Combining the helpers' returns into the final result. It is the point where details drift or get lost (no single helper saw the whole), so you verify it against the sources.Subagents and orchestration
Metadata
Hidden data a file carries beyond its visible content: tracked changes, comments, document properties, cropped-off image regions. It can leak what you thought you removed, so redaction must strip it too.Give Claude things to read
Missing context
A cause of bad answers where Claude lacked something it needed, like an unattached file; the fix is to supply it, not to retry.When things go wrong
Model tier
The size class of the model. Smaller tiers (the fast tier) are quick and cheap; larger tiers (the top tier) think harder and cost more. Three roles: fast, everyday, top.Pick the right model

N

Name the Shape
Decide the form of the output you need (chat reply, table, document, or page) before you ask, based on what you will do with it next.Outputs: documents, tables, and pages

O

One Job, Least Access
The rule for connectors: name the single job first, then grant only the minimum access that does it.Connectors in regular chat
Operational failure
Breaking something on purpose (a tool times out, a step fails halfway, a file is missing) to show the workflow stops safely, logs it, and recovers from backup.Capstone: build and defend a system
Orchestration
Splitting a job across helpers, then combining their short results into one answer in the main chat. The chat doing the combining is the orchestrator.Subagents and orchestration

P

Page or tool
An interactive output other people will operate: a small calculator, form, or web page; availability depends on your plan and features.Outputs: documents, tables, and pages
Pilot
A small, time-boxed trial with volunteers on one use case, run before any wider rollout, small enough that problems stay cheap to fix.Rolling AI out to a team
Plain text
Text with no hidden fonts, colors, or layout, just characters. Because there's nothing hidden to lose, it moves cleanly between tools, unlike word-processor formatting that lives in the file around the text.Markdown and the .md file family
Plan first, act second
Get Claude's full ordered plan before any step runs. The plan is the only moment where reviewing a step is still cheap, because review after the action is too late.Planning, delegation, and human gates
Practice on a safe target
Running the agent first on a test account, sandbox, or throwaway copy where a mistake costs nothing, so you can see what it actually clicks before it touches anything real.Claude in the browser and desktop app
Primary source
The source closest to the fact itself, like a maker's own page for its price; authoritative on what the fact is, though often biased on quality.Research and web search
Privacy-aware log
A log that reconstructs a run (timestamp, ticket id, tag, action) while redacting the body and storing no credentials, so it helps you without becoming the next leak.Guided build lab, part 2: log, stop, restore
Prohibited case
A request the workflow must never fulfill: using unauthorized data or taking an irreversible action without approval. A correct result is a refusal or a stop at the gate.Verification and evals
Project
A workspace that carries a standing set of instructions and files into every chat inside it, so you don't re-explain your background each time. The first tool here that persists context across chats.Projects, files, and instructions
Project vs personal skill
Project skills live in .claude/skills/ inside a repo and are shared with that project; personal skills live in ~/.claude/skills/ and follow you across every project.Reusable skills
Prompt injection
An instruction hidden in a web page, email, or document that tries to give Claude orders. Anything Claude reads from outside is untrusted data, not a command.Tools, scripts, MCP, and untrusted input
Publish gate
A required human review before anything goes live: AI drafts, a person approves. Publishing is a one-way door, so the review happens every time.Public workflows: research and publishing

R

Read-only access
Permission for Claude to see an app's data but not change or send anything; choose it whenever the connector offers it and the job does not need action.Connectors in regular chat
README
A short file at the top of a folder that explains what lives where. Point Claude at it and it has a map instead of a guess. (Unlike Claude Code's CLAUDE.md, a generic README isn't loaded automatically.)Filesystem as context
Reconcile disagreements
When sources differ, finding why (date, region, model, a sale) rather than averaging; the reason tells you which to trust or to keep digging.Research and web search
Recovery drill
Actually restoring from a backup or rollback point and recording the date and result. An untested recovery plan is a guess.Automation and safetyGuided build lab, part 2: log, stop, restore
Redact
Deliberately remove sensitive items from a document before sharing. Do it safely: work on a copy, remove hidden text, comments, and metadata (not just what's visible), export or flatten if needed, then reopen and search/copy-test to confirm it's actually gone.Give Claude things to read
Reproducible
A script or tool does the same steps the same way every time, so it beats guessing at arithmetic, but reproducible is not the same as correct, so you still spot-check.Tools, scripts, MCP, and untrusted input
Required expertise
Whether you can tell a good answer from a confident wrong one. If you cannot verify the output, you cannot safely rely on it.Should AI do this?
Reserved names
Skill names to avoid (anthropic-skills and synced) because Claude Code reserves them and a folder with either name won't behave.Reusable skills
Retrieval test
Asking Claude a question about your notes and checking whether it finds the right ones. A discoverability miss (vague title, missing link) is one a person would hit too, so fix titles and links; an access, indexing, or link-parsing miss is the tool's setup, not your notes, and a person could still find the note.Second brain: notes Claude can use
Reversibility
Whether a wrong result can be undone. Drafts are forgiving; sends, deletions, and publishes are closer to one-way doors and need more care.Should AI do this?
Reversible
A step you can undo. Reversible is not the same as harmless: a reversible step can still expose data, contact people, or cost money on the way, so it may still need a gate.Planning, delegation, and human gates
Review actions
Checking before Claude sends or changes anything when a connector can act, not just read.Connectors in regular chat
Right Context, Not More Context
The four-part check before you send: Goal, Material, Audience, Limits. Relevant beats more; if you could not do the task from only what you pasted, Claude probably cannot either.Give Claude the right context

S

Safe by design, not sandboxed
The workflow stays in its folders because the script is written that way and a human reads it before running it, not because the operating system forces it. Running Python yourself in a terminal has no per-action permission prompt; the only enforced human gate is the script's approved/ step, which stops the send (the risky action), not every action. Honest confinement, not a hard boundary.Guided build lab, part 1: plan, restrict, gate
Safe case
A normal or realistic input, including the awkward-but-valid ones like odd formats and missing data. The eval sheet calls for five of these.Verification and evals
Sample rows
A few real rows pasted so Claude sees the actual shape and the edge cases (blanks, odd values, status rows) that decide whether a formula is correct or merely plausible.Claude with spreadsheets and data
Sandboxing
A Claude Code feature for real containment of what commands can reach. The folder you launch in only narrows the work; it is not a hard sandbox on its own.Claude Code: your first safe session
Say the Finish Line
The five-part frame for a reusable prompt: Task, Audience, Details, Format, Check. Use one line for a quick question; say all five for something you will send, reuse, or depend on.Write a prompt like a spec
Scope
How much a connector can reach: one app is narrow, several at once is wide. The wider the scope, the more Claude can see and the more there is to go wrong.Connectors in regular chat
Search
Asking Claude to look up current information when the answer changes over time; without it, time-sensitive facts may be out of date. Some setups search automatically, some do not.Research and web search
Share less
Remove or hide private material the question doesn't need before attaching: account numbers, IDs, addresses, other people's details.Give Claude things to read
Skill
A folder with a SKILL.md file (a short header of name and description, plus instructions) that Claude loads automatically when the description matches your request, or that you run directly by typing /skill-name.Reusable skills
SKILL.md
The file that defines a skill. The --- line must be the very first line of the file; the header carries the name and description, and the body carries the steps.Reusable skills
Small slice first
Running a new formula or transformation on a handful of rows before the whole sheet, so a mistake costs a few rows you can eyeball rather than corrupting everything.Claude with spreadsheets and data
Source every material claim
Grounding each material factual claim (date, number, named fact) in a specific authoritative source you opened and recording claim, link, and date; not a footnote on every sentence.Public workflows: research and publishing
Spec
A prompt that describes the finished result (what it is, who it is for, what it must contain, and how you will know it is right) rather than just naming the topic. It leaves Claude nothing critical to guess.Write a prompt like a spec
Standing instructions
Rules you write yourself: tone, format, the role you want Claude to play. You state them on purpose, so they're exact and apply across chats. Stable style rules belong here. Exact names vary by plan.Memory and standing instructions
Start Low, Climb on Evidence
The picking rule: start low, read the result, and only when it falls short climb exactly one step, raising effort first, then a tier if effort alone isn't enough.Pick the right model
Subagent (helper)
A separate Claude instance given one focused piece of a larger job. In many tools (such as Claude Code), each helper runs in its own isolated context; whether it inherits any context from the orchestrator, and whether its transcript is visible upstream, varies by tool and platform.Subagents and orchestration
Synthetic data
Obviously made-up practice data (here, invented support tickets) used so you can build and break a workflow without touching any real or sensitive information.Guided build lab, part 1: plan, restrict, gate

T

Table
A rows-and-columns output, best when you need to compare items across the same attributes or calculate totals. A Markdown table rendered in chat, a CSV file, and a spreadsheet workbook are different artifacts; ask for the specific one you need.Outputs: documents, tables, and pages
Task suitability
Whether the work is the kind a language model is good at (drafting, summarizing, extracting, reshaping, coding). For exact arithmetic or live data, the model on its own is wrong, but a model that uses a tool (a script, a calculator, a query) to compute the answer is fine.Should AI do this?
Terminal
A text window where you type commands to your computer: Terminal on Mac, PowerShell or Windows Terminal on Windows, your terminal app on Linux.Bridge: the terminal, paths, and Git
Thin pages
Mass-produced, low-value content made for search traffic rather than readers, penalized by many platforms and bad for trust.Public workflows: research and publishing
Threat model
An upfront look at what could go wrong, who could abuse the automation, and what data it touches, done before you build, not after an incident.Automation and safety
Thresholds
The success, stop, and expand lines written down before the pilot starts, so the final decision is a comparison against a pre-set bar, not an argument about momentum.Rolling AI out to a team
Time payback
Setup hours divided by net hours saved per week, where net is the gross weekly saving minus the weekly upkeep hours (prompt tuning, re-evals). Pure time; the per-run review is already inside the after-time so it is not subtracted again, and ongoing dollar costs belong in financial payback. No payback if upkeep wipes out the saving.Measuring AI's impact
Training cutoff
The point in time up to which Claude learned from text. Facts that changed after it can be wrong unless Claude searches for current information.Research and web search
Training knowledge
Claude's broad, general knowledge from before this chat. It can be out of date, and it contains nothing specific to you, so personal or recent facts must be supplied in the context or fetched by a tool.Give Claude the right context
Trim
Removing files you don't need. Because Claude retrieves relevant slices rather than reading everything, a big pile slows and blurs answers, keep only what you'll reuse.Projects, files, and instructions

U

Untrusted input
Outside content (web pages, emails, documents, other people) that may contain hidden instructions and must not trigger sending, deleting, or spending without your approval.Tools, scripts, MCP, and untrusted inputAutomation and safety
Usage limit
Your overall allowance over time, a tank that refills on a schedule. A bigger context pile drains it faster per turn, so long chats hit the limit sooner even when each new question is short.Why you hit your limit

V

Vault
A folder of small markdown notes linked to each other. An app like Obsidian turns the folder into a browsable vault and shows backlinks.Second brain: notes Claude can use

W

Working folder
The folder the terminal is currently sitting in; commands act on it, so `pwd` shows it and `cd` moves between folders to make commands run where you expect.Bridge: the terminal, paths, and Git
