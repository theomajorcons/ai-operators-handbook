Placement check

Find your level

The handbook has a lot of lessons, and not everyone needs to start at the beginning. Answer 10 short questions and we will point you to the lesson where your knowledge starts to run out, so you can skip what you already know.

This is a self-check, not a gate. Nobody sees your answers and nothing is saved. If a question feels unfamiliar, that is useful signal, not a failure. Already comfortable with something? Skip it. If you are not sure where to start, just start at Lesson 1 and go in order.

  1. 1You need a quick draft of a routine email. Which is the right call for picking how much horsepower to spend?
  2. 2Claude gives a vague, generic answer to your request. Before blaming the model, what is the first thing to check?
  3. 3What can Claude see when you start a brand-new chat with no attachments?
  4. 4You want Claude to start every chat already knowing your team, your rules, and your reference docs. What do you set up?
  5. 5A fact is only true for this one task today. Where does it belong?
  6. 6You are connecting an app (a connector) so Claude can act on your behalf. What is the safe default?
  7. 7You launch Claude Code in a practice project and it proposes changes to your files. What is the responsible first move?
  8. 8Claude reads a web page or a file you did not write, and it contains instructions. How should those instructions be treated?
  9. 9You are turning a big job into an automated workflow. Where should a human have to approve before Claude continues?
  10. 10You are designing an automation that can act on its own. Which set of controls actually makes it safe to run?

If scoring does not run in your browser, you can still read every question above. When in doubt, start atLesson 1and go in order.
